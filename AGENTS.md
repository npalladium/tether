# Repository workflow

Work on the `main` branch by default. Create or use another branch only when the
user explicitly requests it.

Before making changes:

- Inspect the current branch and working tree.
- Preserve unrelated user changes.
- Make small, reviewable commits when commits are requested.
- Verify significant behavior or document consistency before reporting completion.

Do not commit, push, reset, or delete files unless the user explicitly requests
that action.
